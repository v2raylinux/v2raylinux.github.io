访问一号机场官网的下载专区，选择对应操作系统的安装包。Windows 用户通常会得到一个 .exe 文件。双击运行后，请留意安装路径中不要包含中文或空格，这有助于避免后续潜在的路径解析错误。对于 macOS 用户，下载的 .dmg 文件拖入“应用程序”文件夹即可，但首次打开时需在“系统偏好设置 -> 安全性与隐私”中允许来自 App Store 和被认可的开发者的应用。

步骤 2：注册与账户验证

回到官网首页，点击“注册”按钮。建议使用常用邮箱注册，因为后续的密码找回、订阅到期提醒都会发送至此邮箱。注册后，系统会发送一封验证邮件，点击其中的链接完成激活。这一步骤是保障账户安全的第一道防线，切勿省略。

步骤 3：获取订阅配置文件（关键一步）

登录一号机场用户中心，您会看到一个名为“我的订阅”或“一键订阅”的区域。这里通常会提供两种格式的链接：一种是用于 Clash 的 .yaml 文件下载链接，另一种是通用的订阅链接（Sub-URL）。

  • 下载 .yaml 文件：这是最直接的方式。点击下载后，将文件保存在本地任意目录，建议命名为 config.yaml 以便识别。
  • 复制订阅链接：如果您使用的是 Clash 客户端（如 Clash for Windows 或 ClashX），更推荐复制订阅链接。因为当机场更新节点时，您只需在客户端内点击“更新订阅”即可同步，无需重新下载文件。

打开已安装的 Clash 客户端（以 Clash for Windows 为例）：

  1. 在左侧边栏点击“配置”（Profiles）。
  2. 将下载好的 .yaml 文件拖拽至该界面，或者点击“导入”按钮并粘贴订阅链接。
  3. 导入成功后，点击该配置卡片使其变为“激活”状态。
  4. 在左侧边栏点击“主页”（Overview），将“系统代理”开关切换为“开启”。此时，您的系统流量将交由 Clash 接管。

步骤 5：验证连接与模式选择

启动后，观察右下角托盘的 Clash 图标。若为绿色或显示“正在运行”，则说明代理已生效。此时，您可以打开浏览器访问 www.google.com 进行测试。

关于代理模式的选择：Clash 客户端通常提供“规则”（Rule）、“全局”（Global）和“直连”（Direct）三种模式。

  • 规则模式：强烈推荐日常使用。一号机场的配置已内置规则，国内网站直连，国外网站走代理，智能且高效。
  • 全局模式：所有流量均通过代理节点。适用于需要隐藏真实 IP 或访问某些对地区要求严格的服务的场景，但会拖慢国内网站的访问速度。
  • 直连模式：不使用代理，等同于关闭 Clash。

四、进阶配置：让一号机场 Clash 更懂你

安装只是开始，真正的乐趣在于配置。一号机场的配置文件虽然开箱即用，但通过适当调整，可以让您的网络体验更上一层楼。

1. 代理模式与策略组调整

打开 Clash 的“配置”页面，点击当前激活配置的“编辑”按钮（通常是一个铅笔图标）。您会看到 YAML 格式的源码。对于新手，不建议直接修改大段代码，但您可以关注以下几个关键部分：

  • proxies：这里列出了所有可用的代理节点。每个节点包含名称、服务器地址、端口、加密方式等信息。
  • proxy-groups：这是策略组。一号机场通常会设置“自动选择”（自动测速选择延迟最低的节点）、“手动选择”（您自己点击切换）以及“故障转移”等策略。建议将“手动选择”作为常用策略，以便在观看不同地区流媒体时灵活切换。

2. 规则（Rules）的妙用

规则决定了哪些流量走代理，哪些流量直连。一号机场的默认规则已经非常完善，但如果您有特殊需求，例如想让某个特定网站（如某个游戏服务器）强制走代理或直连，可以手动添加规则。

在 YAML 文件的 rules 部分，格式通常为 - 类型, 条件, 策略。例如： - DOMAIN-SUFFIX, example.com, 手动选择 这表示所有以 example.com 结尾的域名都走“手动选择”策略组。

3. DNS 与节点延迟优化

在 Clash 配置中，DNS 设置对于防止 DNS 污染至关重要。一号机场的配置通常已开启 enhanced-mode: fake-ip，这能有效提升解析速度并规避污染。如果您遇到某些网站打不开的情况，可以在“主页”界面点击“测速”按钮，重新选择延迟最低的节点。定期更新订阅也是保持节点活跃度的重要手段。

五、常见问题解答：排忧解难，顺畅上网

在使用过程中，难免会遇到各种小问题。结合一号机场官网的 FAQ 及笔者经验，为您梳理如下：
